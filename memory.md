# Project memory

- Public install source is `github:tanulmittal/wifi-cli` with npm `--install-links`; the scoped npm package was intentionally dropped.
- Normal CLI use must not download dependencies. `openwifi upgrade` explicitly uses GitHub and requires internet access.
- A real Ubuntu 26.04.1 server uses Netplan + `systemd-networkd` + `wpa_supplicant` over WiFi. The user confirmed physical console access. An experimental timed Netplan connection is being prepared on a test branch; do not call it live-verified until the user tests it. Never replace its network manager remotely.
- The user initially preferred to run server commands themselves, then explicitly authorized direct SSH testing. Do not operate their Termius UI or store credentials.
- Real-host beta testing exposed `wpa_cli` escaped SSIDs and a misleading guided Forget path. A beta.1 trial saved an iPhone SSID containing literal escaped UTF-8 bytes while the server returned to Airtel. Netplan's `try --config-file` copies the candidate to a timestamped filename ending `.yaml`; this remains active after confirmation. The initial Forget removed only the stable file, leaving the timestamped copy and disabled runtime entry. A second openwifi-created Airtel profile is active. Beta.4 Forget removed the inactive iPhone runtime entry on the real host; merged Netplan configuration lists only Airtel and Airtel stayed connected. Beta.4 also removes newly generated timestamped trial copies; real-host connection validation remains pending.
- npm treats a Git dependency containing an npm `build` script as needing preparation. On the server's npm 9, that nested install collided with the existing global package (`ENOTEMPTY`). The development command is `npm run bundle`; the Git install uses committed `dist/` files.
- The user's Ubuntu host has Python/PyYAML and Netplan but no `rfkill`. Do not auto-install Ubuntu tools; radio on/off must fail clearly on that host. Netplan edits use bundled JavaScript YAML parsing, so no host Python dependency is needed. Live edit, disconnect, and connection trials are not yet verified.
- The global server install changed from beta.6 to main's 0.1.4 between screenshots and SSH inspection, suggesting another installer touched it. Pin test installs to an exact Git commit and compare the installed `dist/openwifi.cjs` SHA-256 with the locally tested bundle before interpreting live results. Beta.7 exact-commit installation matched and safe CLI checks passed.
