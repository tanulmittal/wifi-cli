# Architecture

The TypeScript entry point in `src/cli.ts` parses commands; `src/interactive.ts` handles guided prompts. `src/adapters/index.ts` selects Linux or macOS. `src/util.ts` runs system commands without a shell and provides the mocked runner used in tests. `src/upgrade.ts` resolves the newest `v*` release tag on GitHub and reinstalls that exact tag, refusing to downgrade. `src/trial.ts` owns the detached Netplan trial worker, its state file under `/run/openwifi`, and `src/version.ts` holds the single version string shared by the CLI and the upgrade check. A bundled YAML library edits Netplan documents without an Ubuntu package download at runtime.

Linux backend selection prefers `nmcli`, then `iwctl`, then `wpa_cli`. NetworkManager handles full reads and writes. `iwctl` provides scan/status. `wpa_cli` provides scan/status/list; its SSID parser decodes escaped UTF-8 bytes and ignores invalid entries. When Netplan is present, `src/adapters/netplan.ts` rejects an already saved target with a hint to use `openwifi use`, then writes a candidate access point to `/run/openwifi` mode 0600 and starts a detached worker (`openwifi __trial`) in its own session so an SSH drop cannot cancel the trial. The worker adds the candidate through a 90-second `netplan try`, selects it in wpa_supplicant, verifies SSID and IPv4 twice, confirms the trial, copies the candidate into `/etc/netplan` mode 0600, and removes newly generated content-matching timestamped copies. It records phases and the outcome in `/run/openwifi/connect.json` (0644, no secrets) with raw output in a root-only log, and always deletes the candidate because that file holds the WPA password. `openwifi status` surfaces the last trial, `use <ssid>` reselects a saved runtime network without writing configuration, and `doctor` compares `/run/netplan/wpa-<iface>.conf` against the saved Netplan config so `doctor --fix` can regenerate it after an unfinished trial. Forget removes all matching inactive openwifi profile YAML files, including beta.1 escaped-SSID and timestamped copies, and removes matching runtime entries without applying the network configuration. Edit locates one source profile (or identical timestamp duplicates), preserves unrelated YAML settings, validates through `netplan generate --root-dir`, and trials active edits with forced reauthentication before saving; active edits stay in the foreground. Autoconnect/priority fail closed. `wpa_cli disconnect` is temporary; installed `rfkill` controls radio power. macOS uses `networksetup` and system discovery tools. The build emits a bundled `dist/openwifi.cjs` executable for offline runtime use.
