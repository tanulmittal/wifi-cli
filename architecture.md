# Architecture

The TypeScript entry point in `src/cli.ts` parses commands; `src/interactive.ts` handles guided prompts. `src/adapters/index.ts` selects Linux or macOS. `src/util.ts` runs system commands without a shell and provides the mocked runner used in tests. `src/upgrade.ts` reinstalls the public GitHub package on request.

Linux backend selection prefers `nmcli`, then `iwctl`, then `wpa_cli`. NetworkManager handles full reads and writes. `iwctl` provides scan/status. `wpa_cli` provides scan/status/list; its SSID parser decodes escaped UTF-8 bytes and ignores invalid entries. When Netplan is present, `src/adapters/netplan.ts` rejects an already configured target, then connects by adding a candidate access point through a 90-second `netplan try`, selecting it in wpa_supplicant, verifying SSID and IPv4, confirming the trial, and copying the candidate into `/etc/netplan` mode 0600. The candidate lives under `/run` and is removed after the attempt. Forget unlinks only inactive profiles whose hashed filename was created by openwifi, with a content-checked fallback for beta.1 escaped SSIDs; it does not reconfigure live networking. Other Netplan writes fail closed. macOS uses `networksetup` and system discovery tools. The build emits a bundled `dist/openwifi.cjs` executable for offline runtime use.
